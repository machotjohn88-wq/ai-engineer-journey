# Student Marks Analyzer 📊

This is a simple Python project that analyzes student marks.

## Features
- Takes 5 marks as input
- Displays:
  - Highest mark
  - Lowest mark
  - Average mark
- Sorts marks (ascending & descending)
- Assigns grades:
  - A (90+)
  - B (75–89)
  - C (50–74)
  - F (<50)

## How to Run
1. Open terminal
2. Run:
   python student_marks_analyzer.py
